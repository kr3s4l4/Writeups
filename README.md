## 🚀 Cómo usar este repositorio

1. Navega a la carpeta del CTF que te interesa
2. Cada reto tiene su propio README.md con la solución
3. Los scripts y herramientas usadas están en las mismas carpetas

---

## 📝 Contribuciones

Si quieres añadir tus propios writeups:
1. Crea una carpeta con el nombre del CTF
2. Añade un README.md con la solución
3. Incluye scripts o herramientas usadas
